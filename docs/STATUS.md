## 档 B：小调度器（2026-11-11）✅ 综合通过

### 形态

CPU 不碰视觉数据流，只做**帧级调度**：读结果 → 去抖 → 放行。

```
post_cv3_conv2d ─► frame_argmax (clk_pe 148.5MHz)
                        │ tgt_valid / tgt_packet / det_count
                        ▼
                   rv_mmio  ◄──► RV32 (pixclk 74.25MHz)
                   寄存器桥        读 0xA000F000..0x00C
                                  写 0xA000F010 (gate)
```

### 接入点：用 SoC 现成的 shared MMIO 窗口

ARES 的 `perip_bridge` 已经有一个未使用的共享窗口（`addr[31:8] == 24'hA000F0`），
`student_top` 把它作为 `shared_*` 端口暴露出来。**利用它就不需要改 ARES 的任何源码。**

| 偏移 | 方向 | 内容 |
|---|---|---|
| 0x00 | R | 最近一次检测 `{cls, x, y, conf}` |
| 0x04 | R | 包序号（每来一个新检测 +1） |
| 0x08 | R | sticky：出现过检测 |
| 0x0C | R | 该帧检测数 |
| 0x10 | RW | 控制位 bit0 = gate |
| 0x14 | RW | 预留阈值 |

跨时钟：视觉→CPU 用 **toggle 握手**（数据保持、翻转同步）；CPU→视觉的 gate 是准静态位，**两级同步器**。

### 固件

`rtl_rv/fw/scheduler.c`（约 40 行 C）+ `start.S`：读序号 → 判类别一致 → 连续 3 帧稳定则开闸。
编译产物 **156 字节 / 39 条指令**，工具链 `riscv-none-elf-gcc 15.2.0`。

### 实测面积（真实固件，synthesize）

| 资源 | 基线（无核） | B 档（含核） | 增量 |
|---|---|---|---|
| LUT | 78,758 / **49.29%** | 86,720 / **54.27%** | +7,962（+4.98 pt） |
| FF | 100,825 / 31.55% | 107,209 / 33.55% | +6,384 |
| DRM | 222.5 / 53.61% | 240.5 / **57.95%** | +18 |
| APM | 261 / 35.27% | 281 / **38.0%** | +20 |
| LUTRAM | 1,318 | 1,990 | +672 |

**注意**：真实固件的结果（86,720）与随机指令流（86,832）几乎一致，说明这个程序已经让
数据通路基本全活，**+8k LUT 是可信的数字**，不是被剪枝的假象。

### 仍然带着的冗余

`USE_ICACHE=1` 和三个 CoreMark 加速器仍在。按此前实测，砍掉加速器可再省约 2,799 LUT / 16 APM，
预计回落到 **LUT ≈51.5%**。

### 未验证

- **上板**：未烧写，行为未在硬件上确认。

## 档 A：控制器遥测出板（2026-11-11）✅ 综合通过

### 现状

没有传感器资料，所以先做**通路**：`ctrl_frame` → `uart_tx` → 一根引脚。
输入侧用 `DEMO=1` 的内建三角波发生器占位，接上真实 IMU 时把 `DEMO` 改 0、接 `s_ax/s_ay/s_az/s_btn` 即可。

### 帧格式（12 字节，约 100 Hz，115200 8N1）

```
[0] A5   [1] 5A   [2] seq   [3] jx   [4] jy
[5] ax[15:8]  [6] ax[7:0]  [7] ay[15:8]  [8] ay[7:0]
[9] az[15:8]  [10] az[7:0] [11] buttons[7:0]
```

一帧 12 字节 ≈ 1.04 ms @115200，占 100 Hz 周期约 10%。

### 关键结论：两条线可以进同一个位流

| 配置 | LUT | IO | DRM | APM |
|---|---|---|---|---|
| 视觉基线 | 78,758 / 49.29% | 136 | 222.5 | 261 |
| 视觉 + RV 核 | 86,720 / 54.27% | 136 | 240.5 | 281 |
| **视觉 + RV 核 + 控制器 UART** | **86,844.5 / 54.35%** | **137** | 240.5 | 281 |

**控制器通路只多花 124 LUT、178 FF、1 个 IO。** 基本是免费的。

### 一个已知的冲突点

板子只有一根可用的 UART TX 引脚，而现在：

- 控制器帧**独占**这根线（100 Hz 周期性）；
- RV 核的 UART（将来发 `TGT,...`）**没有接出去**——`rv_top` 里 `uart_tx` 仍然被固定为 1。

两条数据流要共用一根线，需要一个**发送仲裁器**（按字节粒度授权，不能在一个字节中间切换）。
这是下一步要做的事，不是现在的问题。

### 未做

- **引脚约束**：`uart_ctrl_tx` 还没有分配物理引脚，需要 200Pro+ 原理图确认一个空闲 IO；
- **上板**：没有验证过实际波形；
- **PnR**：仍只到 synthesize + dev_map。
