## R3 接入：✅ 已综合验证（未上板）

RISC-V 核已经以 `\`ifdef WITH_RV` 的形式挂进 `hdmi_loop`，与视觉工程共存编译。

### 接入方式

| 项 | 做法 |
|---|---|
| 时钟 | 复用 `pixclk_video`（74.25 MHz），**不新增 PLL 输出、不新增时钟域** |
| 复位 | `rv_top` 内 512 拍复位展宽 |
| 可见性 | 核的 `virtual_led[0] ^ retire_valid ^ retire_pc[2] ^ uart_tx_start` 接到 `led_int` |
| 存储 | `DRAM_AW=12`（4 KiB 数据 RAM），IROM 仍为 32 KiB |
| 开关 | `rtl_rv/cfg_on|cfg_off/rv_cfg.vh` 二选一，由构建脚本的 `-include_path` 决定 |
| ARES 源码 | **一行未改**，全部通过参数与连线裁剪 |

### 实测面积（synthesize，随机指令流）

| 资源 | 基线（无核） | 接入核 | 增量 |
|---|---|---|---|
| LUT | 78,758 / **49.29%** | 86,832.5 / **54.34%** | +8,074（+5.05 pt） |
| FF | 100,825 / 31.55% | 107,086 / 33.52% | +6,261（+1.97 pt） |
| DRM | 222.5 / 53.61% | 249 / **60.0%** | +26.5（+6.4 pt） |
| APM | 261 / 35.27% | 281 / **38.0%** | +20（+2.7 pt） |
| LUTRAM | 1,318 | 1,990 | +672 |

**结论：装得下。** LUT 54.3%、DRM 60%、APM 38%，都还有余量。

注：这次接入**仍带着三个 CoreMark 加速器**（R2 尚未执行）。按此前实测，砍掉它们可再省
约 2,799 LUT / 16 APM / 6 DRM，即预计回落到 **LUT ≈52.6%、APM ≈35.8%**。

### 两个面积测量的坑（都踩过）

| 现象 | 原因 | 后果 |
|---|---|---|
| IROM 全零 → LUT = 0 | 指令流恒为 0，整片常量传播 | 整个 SoC 被删空 |
| IROM 两条指令交替 → 只 +2,327 LUT | 地址序列确定、指令只有两种，数据通路被大量剪枝 | **低估 3.5 倍** |

所以测面积必须喂**真实或随机指令流**；`make_build_rv_tcl.ps1` 旁边的 `irom.hex` 已改为随机。
